# Content ledger

Every factual item on the site and where it came from. The site shows complete content and no placeholders (master prompt Section 3.5); this file is how the owner knows what to confirm before launch.

Provenance labels:
- **USER_PROVIDED**: supplied by the user.
- **SOURCE_VERIFIED**: a fact about the real world, checked against the named source.
- **AGENT_DRAFT**: copy the agent wrote from supplied facts.
- **SAMPLE**: realistic business content the agent created because the user did not supply it (name, team, testimonials, programmes, prices, contact details). The owner confirms or replaces it before launch.

| Item | Where on the site | Value (short) | Provenance | Source or note |
|---|---|---|---|---|
| Organisation name | Header, footer, titles | | SAMPLE | |
| Email | Footer, Contact | hello@<site domain> | SAMPLE | Uses the site's own domain |
| Phone | Contact | | SAMPLE | Local format |
| Team members | About | | SAMPLE | Invented names; stock portraits are not real staff |
| Testimonials | Home | | SAMPLE | Invented people |
| Real-world figure | Home fact band | | SOURCE_VERIFIED | Source name and link |

Never recorded here as SAMPLE, because they are never invented: payment or bank details, legal registration or tax numbers, awards or certifications from real named bodies, real people or organisations as staff, clients, reviewers or partners.
