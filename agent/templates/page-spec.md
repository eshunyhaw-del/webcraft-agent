### <Section name>
- **Purpose:** what the visitor should understand or do here.
- **Layout:** container width, columns, alignment, background.
- **Typography:** which type steps and weights.
- **Media:** asset, crop and focal point, loading (eager only above the fold).
- **Copy:** final text or its source; provenance of any fact (see the content ledger).
- **Components:** which shared components, which variants.
- **Responsive:** what changes at each breakpoint (recompose, do not just shrink).
- **Interaction and states:** hover, focus, loading, empty, success, error.
- **Motion:** element, trigger, duration, easing; class (ESSENTIAL / ENHANCEMENT / DECORATIVE); reduced-motion behaviour; no essential information only on hover.
- **Accessibility:** landmarks, heading level, labels, alt text approach.
