# Sample Prompts

Quality and specificity benchmarks for the WEBCraft agent.

The agent reads these before each project to calibrate the level of craft. It learns from how precisely they specify structure, typography, assets, spacing, motion, responsiveness, and acceptance criteria. It never copies their layouts, copy, palettes, brands, or assets.
